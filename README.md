# Godot Social Links

This repository contains the source code for the [Godot social links website](https://links.godotengine.org/), which collects links to Godot's official social media accounts and community platforms.

## Building

You need to install [Jekyll](https://jekyllrb.com/docs/installation/) to build this project.

To build the website run:
```bash
jekyll build
```

Alternatively, you can host the site locally and have jekyll automatically rebuild it upon changes with:
```bash
jekyll serve
```

## Deployment

Changes pushed to `main` are automatically deployed through GitHub Pages.
